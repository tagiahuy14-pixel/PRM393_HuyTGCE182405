# Android screenshots

Captured from the normal `lib/main.dart` app on the Pixel 8 emulator, Android 15
(API 35), at 1080 × 2400. These are runtime captures, not mockups.

- `home_empty.png`: first-launch Home, recovered banner, empty state, Add Item,
  BottomNavigationBar.
- `add_item.png`: complete Add form with default category and Wishlist status.

The banner quality reflects the low-resolution screenshot embedded in the PDF;
the original Resources image was not supplied.
